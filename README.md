# prefrontal‑training‑tool
Python tool to generate random concentric‑circle dot training board for prefrontal cortex training, output PNG image and countdown MP4 video.

## 项目介绍
前额叶专注力训练点阵生成工具。
基于Python实现，随机生成同心圆布局数字训练盘面，支持输出训练图片、倒计时训练视频，用于舒尔特类专注力训练。

## 环境依赖
需要安装第三方库：
pip install matplotlib moviepy

## 文件说明
生成png.py：生成同心圆随机数字点阵，输出 PNG 训练图片
生成倒计时.py：基于点阵数据，生成带倒计时的训练 MP4 视频
使用方法
安装上述依赖库
运行 生成png.py，会在本地输出训练图片
运行 生成倒计时.py，生成倒计时训练视频
项目要点
使用 matplotlib 完成极坐标同心圆点位生成，处理画布比例、背景配色。
moviepy 版本存在 API 差异，需要注意版本兼容，处理图片转视频渲染性能。
坐标转换：极坐标转笛卡尔坐标，象限分色逻辑。
区分：Excel 单元格生成方案，后期迁移到 matplotlib 直接输出图片，避开 Excel 绘图限制。
视频生成需要权衡画布长宽比例、帧率参数。

## 开发背景与心路历程

偶然刷到前额叶专注力训练的相关视频，感觉这类训练很有意义，需要长期每日练习才能看到效果。
但原版作者提供的训练素材数量有限，如果反复使用同一套数字布局，大脑会记住点位位置，会降低实际训练效果。
因此我希望自己开发工具，可以源源不断生成全新的盘面与训练视频。

开发过程经历多轮方案迭代：
1. 最开始选择 openpyxl，通过Python操作Excel单元格去排布数字，完成了表格版本的生成。实践后发现Excel做图形布局很受限，单元格行列单位不一致，很难做出均匀的圆形点阵。
2. 于是迁移到 matplotlib，放弃Excel，直接在代码里做绘图输出图片。
3. 需要实现同心圆点阵：涉及极坐标转笛卡尔坐标的数学计算，调试半径、角度、象限分色，反复调整视觉疏密，中间多次出现图形变形、点位分布不均匀的问题。
4. 后期拓展视频功能，接入moviepy，处理图片帧、画布比例、渲染耗时等问题。

中间踩过不少坑：
- 混淆库的安装和导入，初次接触第三方库，理解`pip安装`和`import导入`的区别。
- 图形坐标调试，肉眼很难判断偏移量，反复修改参数看输出效果。
- 工具选型取舍：不是一开始就确定最终方案，不断对比不同工具的优缺点，推倒旧方案重构代码。

整个项目既是一个实用训练工具，也是我练习Python第三方库、数据可视化的实践。
